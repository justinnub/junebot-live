Quote Relay setup

Combined prices come from the JuneBot Quote Relay Chrome extension, which reads the actual bet slip in your own signed-in Chrome. Nothing is multiplied or modeled, and it never places a bet.

1. Chrome → chrome://extensions → Developer mode → Load unpacked → choose Desktop/NHL/junebot-relay.
2. Click the JuneBot extension icon, paste the relay key below, save.
3. Turn on Auto-price for bet365 and FanDuel. Each opens its own window; leave those windows open (not minimized).

If a book page changes and prices stop arriving, open that book's worker window, click the extension and choose Send page snapshot; the snapshot is saved under scanner/work/hockey/relay-debug for recalibration.
